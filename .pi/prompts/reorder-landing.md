Шаг 6. Только после моего подтверждения правь код. Правила для Next/React:

Меняй только порядок вызова компонентов/секций в родительском файле страницы. Сами компоненты не редактируй.

Server vs Client Components: не добавляй и не убирай "use client", не превращай server-компоненты в client и наоборот. Если для дубля CTA нужен интерактив — используй существующий компонент как есть.

Не трогай layout.tsx, metadata, импорты данных (generateMetadata, getStaticProps, server actions) и роутинг.

Не меняй key-пропсы, не переименовывай компоненты, не удаляй импорты — только переставляй.

Если блоки лежат не компонентами, а инлайн-разметкой в одном файле — работай по <section>/<div>-обёрткам верхнего уровня, не трогая вложенность.

Ничего не удаляй и не переписывай тексты; меняется только последовательность (и дубли CTA, если предложил).

Ограничения: не трогай дизайн, копирайт, стили и функционал; не создавай новых файлов и компонентов без моего согласия; не выдумывай новые блоки, кроме дублей CTA. В конце покажи список изменённых файлов и мест (diff или перечень).
